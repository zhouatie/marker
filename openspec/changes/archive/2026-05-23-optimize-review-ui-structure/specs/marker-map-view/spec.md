## ADDED Requirements

### Requirement: 地图 tab 作为独立空间回顾视图
手机应用 SHALL 将地图 tab 呈现为所选日期的独立空间回顾视图，而不是仅作为时间线顶部预览的重复内容。

#### Scenario: 用户切换到地图 tab
- **WHEN** 用户选择地图 tab
- **THEN** 应用展示所选日期中具有可用坐标的标记点和直线连接
- **AND** 地图区域应作为该 tab 的主要内容展示

#### Scenario: 用户切换到时间线 tab
- **WHEN** 用户选择时间线 tab
- **THEN** 应用展示时间段回顾内容作为主要内容
- **AND** 应用不得仅通过隐藏时间线列表来复用同一个地图内容作为 tab 差异

### Requirement: 地图 tab 延续时间段上下文
地图 tab SHALL 使用时间线当前所选时间段作为高亮上下文，并在缺少坐标时保持地图语义清晰。

#### Scenario: 所选时间段包含可定位标记
- **WHEN** 用户在时间线中选择的时间段具有开始或结束标记坐标
- **THEN** 地图 tab 高亮对应的标记点或连接线

#### Scenario: 所选时间段缺少坐标
- **WHEN** 用户选择的时间段没有可用于地图展示的坐标
- **THEN** 地图 tab 不得绘制误导性的高亮路线
- **AND** 应用保留该时间段在时间线中的选中状态

### Requirement: 地图 tab 明确说明连接线语义
地图 tab SHALL 明确表达标记点连接线只是活动边界点之间的直线连接，不代表真实移动路线。

#### Scenario: 地图展示连接线
- **WHEN** 地图 tab 展示两个或多个标记点之间的连接线
- **THEN** 应用展示连接线不代表真实行走路线或连续 GPS 轨迹的说明
