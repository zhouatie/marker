## Why

当前手机端每日回顾界面把设置提示、地图预览和时间线列表混在同一层级，导致主任务不清晰：用户打开时间线时先看到手表快捷入口说明和地图，而不是当天活动时间段。与此同时，时间线 tab 与地图 tab 都展示同一个地图组件，使 tab 切换缺少明确意义。

这个变更要把“每日时间线是主视图、地图是辅助空间视图”的产品意图落到界面结构和交互上，让用户能更快完成当天回顾、选中时间段和补标签。

## What Changes

- 将手机端每日回顾界面重组为清晰的“时间线 / 地图”两个互斥视图。
- 时间线 tab 聚焦活动时间段列表，不再在顶部常驻展示完整地图。
- 地图 tab 升级为独立空间回顾视图，展示所选日期的标记点连接、说明文案和所选时间段高亮。
- 将“手表快捷入口”说明从主回顾内容中移除，不再常驻打断已有时间线；只在需要引导用户配置或没有标记时作为辅助提示出现。
- 优化时间段行的视觉层级和交互反馈，使时间、标签、位置上下文和选中状态更容易扫描。
- 保持现有数据模型、标记同步、标签存储和地图直线连接语义不变。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `daily-activity-timeline`: 调整每日回顾主视图的信息架构，要求时间线 tab 聚焦时间段回顾，并约束手表快捷入口提示不得常驻占用已有时间线顶部。
- `marker-map-view`: 调整地图视图的界面职责，要求地图作为独立 tab 展示完整空间上下文，并与时间线所选时间段保持联动。

## Impact

- 影响手机端 Compose UI：`app-phone/src/main/java/com/atie/marker/phone/MainActivity.kt` 中的每日回顾布局、tab 内容分配、设置提示展示策略、时间段行和地图组件视觉呈现。
- 不影响 Room 数据表、Wear OS Data Layer 同步协议、标记事件模型、时间段推导逻辑和标签持久化模型。
- 不新增第三方依赖。
