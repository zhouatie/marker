## ADDED Requirements

### Requirement: 预设标签包含婴儿照护活动
手机应用 SHALL 在时间段活动标签预设中提供“喂奶”和“换尿布”两个标签，并让它们与其他预设标签一样可选择、可展示、可筛选。

#### Scenario: 选择喂奶标签
- **WHEN** 用户打开时间段标签编辑入口
- **THEN** 预设标签选项中必须包含“喂奶”
- **AND** 用户选择“喂奶”后，手机保存该标签并在该时间段上展示

#### Scenario: 选择换尿布标签
- **WHEN** 用户打开时间段标签编辑入口
- **THEN** 预设标签选项中必须包含“换尿布”
- **AND** 用户选择“换尿布”后，手机保存该标签并在该时间段上展示

#### Scenario: 新增预设标签颜色稳定
- **WHEN** 时间段使用“喂奶”或“换尿布”标签
- **THEN** 时间线列表必须为该标签展示稳定、可区分的颜色
- **AND** 同一个新增标签在标签编辑入口、时间段行和筛选控件中必须使用一致颜色

#### Scenario: 按新增预设标签筛选
- **WHEN** 所选日期存在“喂奶”或“换尿布”标签的时间段
- **THEN** 标签筛选控件必须允许用户选择对应标签
- **AND** 选择后时间线列表只展示所选日期中标签等于该新增标签的时间段
