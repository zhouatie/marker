## ADDED Requirements

### Requirement: 标签颜色稳定展示
手机应用 SHALL 为每个活动标签展示稳定、可区分的颜色，并在每日回顾页面中保持一致。

#### Scenario: 已标记时间段展示标签颜色
- **WHEN** 时间段已经分配活动标签
- **THEN** 时间线列表必须在该时间段的标签 chip 上展示该标签对应颜色
- **AND** 同一个标签在不同时间段上必须展示为同一种颜色

#### Scenario: 标签选择入口展示颜色
- **WHEN** 用户打开时间段标签编辑入口
- **THEN** 预设标签选项必须展示各自对应颜色
- **AND** 当前选中标签必须有明确选中状态

#### Scenario: 自定义标签颜色保持稳定
- **WHEN** 用户保存一个自定义标签并重新打开每日回顾页面
- **THEN** 手机应用必须为该自定义标签展示与保存前一致的颜色

#### Scenario: 未标记时间段使用中性状态
- **WHEN** 时间段没有分配活动标签
- **THEN** 手机应用必须将该时间段展示为未标记状态
- **AND** 未标记状态必须使用中性视觉样式，不能误导为某个活动标签颜色

### Requirement: 用户可以按标签筛选时间线列表
手机应用 SHALL 在时间线列表中提供标签筛选能力，让用户查看全部时间段或只查看指定标签的时间段。

#### Scenario: 默认展示全部时间段
- **WHEN** 用户打开某一天的时间线 tab
- **THEN** 手机应用默认展示该日期的全部时间段
- **AND** 筛选控件必须显示“全部”为当前筛选状态

#### Scenario: 按已有标签筛选
- **WHEN** 用户在筛选控件中选择某个活动标签
- **THEN** 时间线列表只展示所选日期中标签等于该活动标签的时间段
- **AND** 筛选控件必须保留该标签的颜色和选中状态

#### Scenario: 筛选未标记时间段
- **WHEN** 用户在筛选控件中选择“未标记”
- **THEN** 时间线列表只展示所选日期中没有活动标签的时间段

#### Scenario: 回到全部时间段
- **WHEN** 用户在筛选状态下选择“全部”
- **THEN** 时间线列表恢复展示所选日期的全部时间段

#### Scenario: 筛选结果为空
- **WHEN** 当前筛选条件在所选日期下没有匹配时间段
- **THEN** 手机应用必须展示筛选空状态
- **AND** 空状态必须提供回到“全部”的操作

### Requirement: 每日回顾界面具备清晰视觉层级
手机应用 SHALL 优化每日回顾页面的视觉层级，使用户能够快速区分日期控制、视图切换、标签筛选、时间段内容、选中状态和次要操作。

#### Scenario: 顶部控制保持紧凑可见
- **WHEN** 用户查看时间线 tab 并滚动时间段列表
- **THEN** 日期控制、时间线/地图切换控件和当前筛选状态必须保持在列表上方可见
- **AND** 时间段列表滚动不得带走这些顶部控制

#### Scenario: 时间段行信息易于扫描
- **WHEN** 时间线列表展示时间段
- **THEN** 每一行必须明确区分时间范围、进行状态、标签、位置上下文和标记点管理入口
- **AND** 标签编辑入口不得遮挡时间范围或主要内容

#### Scenario: 选中时间段有明确反馈
- **WHEN** 用户选择某个时间段
- **THEN** 手机应用必须在时间线列表中为该时间段展示明确选中态
- **AND** 选中态不得改变该时间段的标签颜色含义

#### Scenario: 空状态与筛选空状态区分
- **WHEN** 所选日期没有任何可展示时间段
- **THEN** 手机应用展示普通空状态和手表快捷入口引导
- **WHEN** 所选日期有时间段但当前筛选无匹配
- **THEN** 手机应用展示筛选空状态，不重复展示手表快捷入口引导
