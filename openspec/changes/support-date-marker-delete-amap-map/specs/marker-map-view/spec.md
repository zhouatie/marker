## ADDED Requirements

### Requirement: 地图使用高德地图承载
手机应用 SHALL 在地图 tab 中使用高德 Android 地图 SDK 展示所选日期的空间回顾内容。

#### Scenario: 高德地图初始化成功
- **WHEN** 用户打开地图 tab 且高德地图 SDK 初始化成功
- **THEN** 应用展示高德地图底图
- **AND** 应用在底图上展示所选日期中具有可用坐标的标记点

#### Scenario: 高德地图不可用
- **WHEN** 用户打开地图 tab 但地图 SDK、API key、网络或权限导致地图不可用
- **THEN** 应用展示清晰的地图不可用状态
- **AND** 时间线 tab 仍然可以用于回顾所选日期

#### Scenario: 地图隐私合规初始化
- **WHEN** 应用准备调用高德地图 SDK 能力
- **THEN** 应用必须先完成 SDK 要求的隐私合规初始化

### Requirement: 地图适配所选日期的标记视野
地图 tab SHALL 根据所选日期中可展示的标记点调整地图视野。

#### Scenario: 所选日期有多个可定位标记
- **WHEN** 地图 tab 展示所选日期中两个或多个可定位标记
- **THEN** 地图视野包含这些标记点

#### Scenario: 所选日期只有一个可定位标记
- **WHEN** 地图 tab 展示所选日期中一个可定位标记
- **THEN** 地图以该标记点为主要视野中心

#### Scenario: 所选日期没有可定位标记
- **WHEN** 所选日期没有包含可用坐标的标记点
- **THEN** 地图 tab 展示无可定位标记的空态

## MODIFIED Requirements

### Requirement: 地图 tab 作为独立空间回顾视图
手机应用 SHALL 将地图 tab 呈现为所选日期的独立空间回顾视图，而不是仅作为时间线顶部预览的重复内容。

#### Scenario: 用户切换到地图 tab
- **WHEN** 用户选择地图 tab
- **THEN** 应用在高德地图上展示所选日期中具有可用坐标的标记点和直线连接
- **AND** 地图区域应作为该 tab 的主要内容展示

#### Scenario: 用户切换到时间线 tab
- **WHEN** 用户选择时间线 tab
- **THEN** 应用展示时间段回顾内容作为主要内容
- **AND** 应用不得仅通过隐藏时间线列表来复用同一个地图内容作为 tab 差异

### Requirement: 地图 tab 延续时间段上下文
地图 tab SHALL 使用时间线当前所选时间段作为高亮上下文，并在缺少坐标时保持地图语义清晰。

#### Scenario: 所选时间段包含两个可定位端点
- **WHEN** 用户在时间线中选择的时间段具有开始和结束标记坐标
- **THEN** 地图 tab 高亮对应的两个标记点和它们之间的直线连接

#### Scenario: 所选时间段只包含一个可定位端点
- **WHEN** 用户在时间线中选择的时间段只有开始标记或结束标记具有坐标
- **THEN** 地图 tab 只高亮对应的可定位标记点
- **AND** 地图 tab 不得绘制误导性的高亮路线

#### Scenario: 所选时间段缺少坐标
- **WHEN** 用户选择的时间段没有可用于地图展示的坐标
- **THEN** 地图 tab 不得绘制误导性的高亮路线
- **AND** 应用保留该时间段在时间线中的选中状态
